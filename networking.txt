      - How the Web Paints:
      The web page rendering process in a browser involves multiple steps: first, the browser downloads the 
      HTML and begins parsing it to build the Document Object Model (DOM). It may encounter CSS, 
      which is a critical resource that must be fully downloaded and parsed before the page can be rendered. 
      Afterward, JavaScript is processed, which can also block DOM parsing depending on how it is included 
      (blocking or non-blocking with defer or async). Once the DOM and CSS are ready, a render tree is created, 
      which includes layout and structuring. Finally, the browser performs painting, visually displaying the 
      elements on the screen. This entire sequence emphasizes the importance of critical rendering paths where
      any blocking resources must be loaded to render the page successfully.
